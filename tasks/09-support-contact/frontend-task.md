# Frontend Task

## Objective

Improve the welcome testimonials section and add a simple, polished support contact page.

## Requirements

- Add a fourth localized testimonial.
- Render 5-star ratings accessibly for every testimonial.
- Use a native horizontal scroll/snap carousel with previous and next controls.
- Replace the organizer support status pill with a link to `/support`.
- Build a support form page using existing shared form and button components.
- Use the public layout for guests and authenticated layout for logged-in organizers.

## Acceptance Criteria

- The testimonial carousel shows three cards on desktop and scrolls naturally on mobile.
- Carousel controls have accessible labels and 44px touch targets.
- The support page is responsive, keyboard accessible, and uses existing design tokens/components.
- Form fields have labels, required indicators, helper text where useful, loading state, and error summary support.
- Copy is localized in `pt-BR` and `en-US`.
